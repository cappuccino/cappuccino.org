---
title: "Cappuccino, for Web Apps"
---

> The technology used to create the WWW, brought home to applications running within it.

In late 1990, Tim Berners-Lee built `WorldWideWeb`—the first web browser and editor—on a NeXT workstation using NeXTSTEP and Objective-C. He chose those object-oriented frameworks because they gave a single developer enough leverage to build a graphical hypertext client and WYSIWYG editor in months rather than years.

Cappuccino is a transliteration of that same application architecture—AppKit and Foundation—to the web browser through Objective-J, carrying it as far as the browser platform allows. In a real sense, the first web client was born inside this model; bringing it back into the browser returns application development to where the web began.

Cappuccino provides a complete application framework out of the box—with document models, undo/redo stacks, responder chains, drag-and-drop protocols, window management, and unified event routing built into a single cohesive model—instead of leaving teams to assemble view libraries, state stores, styling utilities, and routing or layout primitives from scratch on each project. It is built for productive web application development where longevity, maintainability, performance, and an absence of arbitrary functionality-scaling ceilings are required.
